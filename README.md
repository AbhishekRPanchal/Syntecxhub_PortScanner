# Syntecxhub Port Scanner 🔍

A multithreaded TCP Port Scanner built as part of the Syntecxhub Cyber Security Internship.
This project demonstrates socket programming, concurrency, exception handling, logging, and basic network scanning techniques.

Features:

-Scan single ports or port ranges

-Multithreaded scanning for high speed

-Detect open, closed, or filtered ports

Customizable options:

-Host/IP

-Port range

-Number of threads

-Timeout

-Logs results to the console and a log file

-Clean, easy-to-understand Python code
